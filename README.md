# Quantitative Finance Notebooks

A collection of Jupyter notebooks exploring various quantitative finance topics through hands-on implementations and analysis.

##  Contents

### Greeks
- Greeks explained
- Greeks PnL vs real PnL explained (Delta, Gamma, Vega, Theta, Rho)

### Portfolio Optimisation
- Markowitz efficient frontier

### Time Series Analysis
- **ARIMA** - AutoRegressive Integrated Moving Average modeling

### Stock Market Analysis
- Returns distribution and correlation studies, Analysis and visualization of stock market data

##  Technologies

- Python 3.x
- Pandas, NumPy
- Matplotlib, Seaborn
- Statsmodels
- yfinance (for market data)
